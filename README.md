# gunta/tap

Homebrew formulae for the turbo tools.

```bash
brew install gunta/tap/turboblake
```

| formula | what |
|---|---|
| [`turboblake`](Formula/turboblake.rb) | BLAKE3, turbocharged: the official `b3sum` with a Bend2 engine, a drop-in for `b3sum` and `sha256sum`. [Site](https://gunta.github.io/BLAKE3-bend/), [source](https://github.com/gunta/BLAKE3-bend). |

The formulae install the prebuilt binaries attached to each project's GitHub
releases (macOS and Linux, arm64 and x86-64), checked against each release's
SHA256SUMS.
